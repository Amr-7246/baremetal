# Engineering Lab

A personal engineering repository focused on building low-level features, experimenting across programming languages, and documenting the progression of problem-solving skills.

## Purpose

This repository serves two main purposes:

* **Bare-Metal Implementations** — Building fundamental features and concepts from scratch across different programming languages to deepen understanding beyond frameworks and abstractions.
* **Problem-Solving Progression** — Recording solutions and thought processes in a modular way, allowing problems to evolve from simple implementations toward more robust and optimized approaches.

The goal is not simply to collect solutions, but to understand **how and why** they work by implementing concepts rather than relying entirely on existing abstractions.

## Languages

Implementations may span multiple programming languages depending on the concept being explored.

## Philosophy

> Build it from scratch. Understand the abstraction. Then use the abstraction.

This repository is an ongoing record of technical exploration, experimentation, and engineering growth.
